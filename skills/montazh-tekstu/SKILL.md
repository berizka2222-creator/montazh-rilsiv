# Монтаж тексту на відео

Таргетолог дає **готове відео** (товар, процес, результат, людина в кадрі) і текст. Ти розкладаєш текст по таймінгу: хук, переваги по черзі, соцдоказ, ціна, кнопка. Кожен рядок — окремий шар з появою, ефектом і зникненням. Потім відкриваєш **редактор з таймлайном**, де таргетолог усе бачить на відео й править руками. Після її «Зберегти для Claude» рендериш фінальний MP4.

**Відео не змінюєш:** не розмиваєш, не затемнюєш, не міняєш кольори. Можна тільки різати шматки й обрізати до 9:16 / 4:5. Затемнення чи блюр — окремі шари під текстом і тільки за проханням.

Пиши українською, простими словами.

## Крок 0. Збери дані

Одним повідомленням спитай те, чого ще немає:
1. **Відео** (будь-який формат; 4K теж).
2. **Текст.** З `ofery-[клієнт].md` (кут, заголовок, переваги, соцдоказ, ціна, кнопка) або з чату. Не переписуєш, лише виправляєш явні описки й кажеш про це.
3. **Стиль:** один зі стилів редактора (покажи список з кроку 4), референс (скрін, пост, рілс, сайт — 1–3 штуки, з одним реченням «що подобається»), або `styl-[клієнт].md` з уроку 2.
4. **Чи потрібно щось за людиною** (напис чи картка позаду людини в кадрі) і на яких секундах. Якщо людини в кадрі немає — пропускаєш.

## Крок 1. Рушій

Завантаж і розпакуй рушій (один раз за чат):
```bash
cd ~ && curl -sL -o mt.zip https://github.com/berizka2222-creator/montazh-rilsiv/archive/refs/heads/main.zip \
 && unzip -qo mt.zip && rm -rf mt && mv montazh-rilsiv-main/montazh-tekstu mt && rm -rf montazh-rilsiv-main mt.zip
pip install -q playwright pillow numpy 2>/dev/null; python3 -m playwright install chromium 2>/dev/null
```
Якщо Chromium уже стоїть в іншому місці, передавай шлях у змінній `CHROME`. Для «за людиною» ще `pip install rembg onnxruntime`.

**Шрифти бренду.** Якщо є файли шрифтів бренду (з дизайн-системи чи від клієнта), поклади їх у `mt/brand/` і створи `mt/brand/fonts.css`:
```css
@font-face{font-family:"Brand Sans";src:url(Назва-Bold.woff2);font-weight:700}
@font-face{font-family:"Brand Serif";src:url(Назва-Italic.woff2);font-style:italic}
```
Без них стилі беруть Manrope і Playfair. Ще 41 шрифт з кирилицею є в бібліотеці редактора.

## Крок 2. Розбір відео

- Тривалість, розмір, звук (`ffprobe`).
- **Склейки:** `ffmpeg -i video -vf "select='gt(scene,0.3)',showinfo" -f null -` → моменти зміни кадру. Нові рядки ставиш на склейки або на 0.1–0.2 с після них.
- 6–8 кадрів з різних моментів → контактний лист, подивись очима: де продукт, руки, обличчя.
- **Обличчя:** детектор облич по кадрах; текст на обличчя не ставиш.
- Скажи коротко: «Склейки на 2.0, 3.5… Обличчя немає, продукт по центру — текст угорі й унизу».

## Крок 3. Чернетка проєкту

Склади `project.json`. Час — у секундах вихідного ролика.

```json
{"name":"Клієнт · креатив 1","video":"/шлях/video.mp4","segments":[{"in":0,"out":13.6}],
 "accent":"#D7192F","accent2":"#FFC3CC",
 "layers":[
  {"role":"title","text":"Такий торт _ти спечеш_\nпісля курсу","start":0.15,"end":2.95,"x":64,"y":330,"w":952,"size":64},
  {"role":"sub","text":"навіть якщо ніколи не пекла","start":0.7,"end":2.95,"x":64,"y":525,"w":952,"size":44},
  {"role":"item","text":"✓ Конструктор на *25* смаків","start":3.0,"end":10.5,"x":64,"y":1180,"w":952,"size":38},
  {"role":"num","text":"4000+","start":10.6,"end":13.6,"x":64,"y":330,"w":952,"size":150,
   "effect":{"type":"countup","from":2800,"to":4000,"dur":1.0,"suffix":"+"}},
  {"role":"price","text":"490 грн","start":11.4,"end":13.6,"x":64,"y":1250,"w":952,"size":96},
  {"role":"old","text":"~~1 960 грн~~","start":11.6,"end":13.6,"x":500,"y":1272,"w":420,"size":56,"effect":{"type":"strike","delay":0.3}},
  {"role":"cta","text":"Отримати доступ →","start":12.2,"end":13.6,"x":64,"y":1420,"w":952,"size":42}]}
```

**Ролі:** `title` заголовок, `sub` підзаголовок, `item` пункт, `num` велика цифра, `price` ціна, `old` стара ціна, `cta` заклик, `label` мітка. Стилі оформлюють кожну роль по-своєму.

**Розмітка в тексті:** `*слово*` — колір акценту, `_слово_` — другий шрифт (курсив), `==слово==` — кольоровий блок, `^слово^` — тільки контур, `~~…~~` — перекреслено, `Бюджет:||$3843` — рядок чека (підпис зліва, сума справа, крапки між ними), `\n` — новий рядок.

**Правила таймінгу:**
- Хук з перших 0.1–0.2 с — перший кадр уже несе зміст.
- Людина читає близько 3 слів за секунду: рядок тримається не менше `слова / 3 + 0.8` с.
- Переваги з'являються по черзі на склейках і **накопичуються** (попередні лишаються), зникають разом.
- Соцдоказ і ціна — в останні 3–4 с, кнопка — останні 1.5–2 с.
- Увесь текст у безпечній зоні y 285–1580 (там, де його не перекриває інтерфейс і 4:5).
- Не на обличчі й не на продукті.

## Крок 4. Стиль

Список стилів: `python3 mt/apply_pack.py --list`.

| Стиль | Коли |
|---|---|
| `simple` Простий | плашки, нейтрально, будь-яка ніша |
| `journal` Журнал | експерти, курси, преміум: капс + курсив, тонкі лінії |
| `kinetic` Кінетика | акції, енергійні товари: великий капс, кольорові блоки |
| `soft` Ніжний | б'юті, догляд, преміум: курсив, скло, зірочки |
| `scrap` Скрапбук | блогерський тон, хендмейд: скотч, стікери, рукописне |
| `glam` Гламур | жіночі продукти, блог: рожеве сяйво, пігулки, ціна купоном, напис на фоні |
| `tiara` Тіара | коучі, консультанти: висока антиква, бордо/крем, стрілки |
| `digital` Digital Wave | курси, школи: м'яка антиква на папері, вкладки, брелок-ціна |
| `luxix` Luxix | косметика, б'юті-товари: щільний гротеск, пудра на бордо, скло |
| `rita` Пастель-колаж | особистий блог, лайфстайл: курсив, жовті наклейки |
| `hotcore` Hot Core | фітнес, спорт, студії: масивний капс + курсив |
| `anya` Каліграфія | естетичні ніші, освіта: каліграфія на картці, блакитні виділення |
| `galeriia` Travel-гайд | подорожі, події, гайди: жирний капс, рукописні підписи |
| `receipt` Чек | кейси, результати, ціни: марка, чек зі штрихкодом, рваний папір |

**З референсу:** розбери таблицею «що подобається → як влаштовано → що беремо» (шрифт і регістр, курсив чи ні, підкладки й форма, кольори, декор, як з'являється). Обери найближчий стиль, застосуй, а потім допиши в шари свої відмінності: шрифт з бібліотеки, `plate`, `plateColor`, `color`, `accent`, `in`. Колір бренду — через `accent` / `accent2`.

Застосувати: `python3 mt/apply_pack.py project.json СТИЛЬ project.json [акцент] [другий]`. Стиль сам розсуває рядки, щоб не налазили, додає фон під текст і декор.

**Під стиль підлаштуй текст розміткою:** у «Журналі», «Тіарі», «Hot Core», «Гламурі» — курсивне слово `_…_` всередині заголовка; у «Чеку» — рядки `||`.

## Крок 5. Редактор у чаті

1. Легка копія відео: `ffmpeg -i video -vf scale=540:-2 -c:v libx264 -crf 26 -pix_fmt yuv420p -c:a aac preview.mp4`.
2. **За людиною** (тільки якщо просили): `python3 mt/make_matte.py preview.mp4 matte.webm 540 "2.0-4.5,8-9"` — лише ці секунди (близько 0.7 с роботи на кадр). Шарам, що мають бути позаду, постав `"behind":true`.
3. `python3 mt/build_artifact.py project.json preview.mp4 montazh.html [matte.webm]` → опублікуй `montazh.html` як артефакт («Монтаж тексту на відео»). Якщо в цьому чаті потім надсилаєш ще файли, відкривай редактор **останнім**, щоб він лишався на екрані.
4. Коротко поясни, як працювати:
   - пробіл — програти; клік по рядку — його налаштування праворуч; тягни рядок по відео, кутик рамки — розмір;
   - таймлайн: тягни смужку — час, краї — початок і кінець; ✂ або S — розрізати відео, клік по шматку — прибрати;
   - «✦ Стиль ролика» — перемикати стилі одним кліком, усе видно одразу, без рендеру;
   - «+ Текст», «+ Фон під текст» (градієнти, блюри, затемнення), «+ Декор» (обведення, стрілки, штрихкод…), «+ Картинка / відео» (з'являються з ефектом);
   - коли все подобається — **«Зберегти для Claude»** → скопіювати → вставити в чат.

## Крок 6. Рендер

Таргетолог вставила JSON → збережи як `project.json` (шлях `video` — на оригінал, не на прев'ю) → `python3 mt/render.py project.json назва`.
Шари `"behind":true` рендер сам вирізає тільки на їхніх секундах.
Готово: `mt/out/назва_9x16.mp4` і `mt/out/назва_4x5.mp4` (4:5 — смуга y 285–1635). Час: близько 3 хв на 15 с ролика.

**Перевір очима** 4–5 кадрів (`ffmpeg -ss T -frames:v 1`): перший кадр, поява кожної групи, ціна, кнопка. Текст не на обличчі, не обрізаний у 4:5, шрифти з кирилицею, нічого не налазить.

## Віддача
- `назва_9x16.mp4` — Stories і Reels; `назва_4x5.mp4` — стрічка;
- `project.json` — щоб потім змінити й перерендерити;
- коротко: стиль, що де стоїть, що змінено в тексті.

## Правки
Голосом або текстом («ціну раніше», «заголовок більший», «інший стиль», «прибери кнопку»): міняєш тільки назване в `project.json` і знову відкриваєш редактор або одразу рендериш, якщо правка дрібна.

## Правила
- Відео не змінюєш. Затемнення й блюр — окремим шаром і тільки за проханням.
- Не вигадуєш цифри, відгуки, ціни — лише з оферів або від таргетолога.
- Мінімум слів, максимум сенсу: один рядок — одна думка.
- Рендериш один фінальний варіант, а не всі стилі.
- Нічого не завантажуєш у рекламний кабінет: віддаєш файли.
