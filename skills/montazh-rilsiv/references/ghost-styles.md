# 18 стилів з ghost-editor: референси для лабораторії стилю

Взято з github.com/kurbaitaev/ghost-editor (MIT, `ghost-styles/LICENSE-ghost-editor.txt`; кілька стилів мають свої
CREDITS / LICENSE у своїй папці). Це **описи вигляду**, не готові шаблони: їхні збирачі (`cleanos.py`, `seoul.py`...) тут
не встановлені і не потрібні. У кожній папці `README.md` (як виглядає, по секундах) і `SYSTEM.md` (правила, слоти,
таймінги), якщо він є.

## Як використовувати
- **Лабораторія стилю** (`references/style-lab.md`): коли людина просить «інші варіанти», «щось нове», «як новини / як
  газета / як дошка», візьми стиль звідси як напрям раунду. Перенеси **патерн** (ритм, де текст, як з'являються слова,
  переходи, звуки) у варіант style json, а кольори й шрифти бери тільки з її бренд-файлу. Чужі кольори (honey, navy, maroon)
  міняй на кольори з бренду.
- **Власний моушн на фразу** (розділ «Own motion design on phrases» у SKILL.md): окрема сцена стилю (сторінка досьє,
  тактична дошка, графік олівцем) стає `custom`-карткою на HyperFrames. Спершу перевір каталог.
- Не змішуй фірмові ходи двох стилів в одному рілсі (правило ghost-editor `references/styles.md`).

## Каталог

| Стиль | Як виглядає | Для чого |
|---|---|---|
| `caption-news` | великі субтитри головні, 2-3 шматки на слово, ключове слово на кольоровій плашці, що протирається; заставка внизу | новини, «сталося», рілси без звуку |
| `clean-os` | чистий інтерфейс-ОС навколо голови: вікна, курсор, системні картки; кожен рілс заповнює слоти новим | поради, бізнес, спокійний преміум |
| `data-story` | коли звучить цифра, на кремовому папері олівцем малюється графік, рукописні примітки, підпис як у науковій статті | цифри, кейси, результати |
| `explainer-vector` | анімований векторний ролик без обличчя, метафора, мудрий голос | ідея без зйомки, притча |
| `halftone-dossier` | ретро-досьє: архівний папір, растрові точки, засічковий заголовок з рожевою тінню, печатки з трусом сторінки | розбір людини / бренду / кейсу |
| `hologram-hud` | обличчя чергується з HUD-сценами: предмет сканується в світний каркас, цілі, цифри «докуються» чипами | техніка, звички, огляд речі |
| `kinetic-doc` | чорно-біла архівна документалка з одним червоним акцентом, слова по одному в рядок, відбитки й полароїди | історії, маніфести, закадровий голос |
| `news-package` | людина як ведуча теленовин: заставка, плашка на грудях, рубрикатор пунктів, підсумок | дайджест, «3 новини тижня» |
| `pov-montage` | кліпи від першої особи (окуляри, GoPro, телефон), день або поїздка, кілька фраз | влог, поїздка, день з життя |
| `product-page` | огляд інструмента як сторінка продукту: людина вирізана над карткою з відео, двоярусні заголовки, слово в пігулці, зум скрінів | огляд сервісу, демо, туторіал |
| `result-podcast` | ностальгійний сторітелінг, фото на кожен приклад | подкаст-монолог, спогади, списки прикладів |
| `seoul-list` | рілс-список з короткими кадрами і елементами, точні таймінги з розбору | «5 речей про...», списки |
| `stan-style` | туторіал по інструменту: скрін-панелі головні, людина поруч | покроковий туторіал |
| `step-deck` | поради як нумерована колода: слова за головою за важливістю, кожні 1-2 с повноекранні картки | поради, кроки, чеклісти |
| `swiss-grid` | швейцарська сітка: 6 колонок, один шрифт, один сигнальний колір, обличчя в смузі сторінки | експертний, стриманий, дизайн |
| `tactile-paper` | газетні сторінки з реальним згином, стоп-моушн 8 к/с, рукописні підписи, звук паперу | історії, «як було», архів |
| `telestrator` | футбольний розбір: відео зупиняється на слові, маркерні стрілки й кола навколо людини, тактична дошка | розбір помилок, «що тут не так» |
| `whiteboard` | половина екрана маркерна дошка, кожне речення малюється маркером, людина внизу | пояснення схеми, воронки, процесу |

Для експертів і наставників найближчі: `data-story` (цифри кейсів), `telestrator` (розбір кабінету / помилок),
`whiteboard` (воронка, схема), `product-page` (огляд інструмента), `step-deck` (кроки), `halftone-dossier` (розбір кейсу).
