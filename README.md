# Монтаж рілсів з Claude

Ти даєш Claude сире відео, де говориш у камеру, і отримуєш готовий рілс у своєму стилі:
- вирізані «ем», «ммм» і довгі паузи;
- субтитри твоїми шрифтами й кольорами;
- хук-заголовок (текст завжди питає в тебе);
- графіка й вставки: картки, скріни, фото, відео в рамці, скло;
- власний моушн на фразах і на весь екран;
- сторінка перевірки, де ти все затверджуєш до рендеру.

Працює українською. Зроблено для учнів TARGET AI.

## Що потрібно
- Mac.
- Застосунок Claude з платною підпискою (Pro або Max).
- 10 ГБ вільного місця.

## Встановлення (без термінала)
1. Відкрий застосунок Claude → вгорі по центру вкладка **Code**.
2. Вибери **Local** → **Select folder** → свою домашню папку (з будиночком і твоїм іменем).
3. Встав повідомлення і надішли:

```
Встанови скіл монтажу рілсів: завантаж https://github.com/berizka2222-creator/montazh-rilsiv/archive/refs/heads/main.zip, розпакуй і поклади папку skills/montazh-rilsiv у ~/.claude/skills/montazh-rilsiv. Потім прочитай її SKILL.md і зроби розділ «First run on a new computer». Термінал мені не пропонуй, усе роби сам і пояснюй коротко українською.
```

4. Погоджуйся на дії, які пропонує Claude. Якщо відкриється вікно встановлення macOS, натисни в ньому «Продовжити» / «Встановити» і введи пароль від Mac. Перше встановлення займає 15–30 хвилин.

## Перший монтаж
1. Застосунок Claude → вкладка **Code** → папка `reels` у твоїй домашній папці (Claude створить її при встановленні).
2. Напиши «змонтуй рілс» і прикріпи відео.
3. Перед першим монтажем Claude попросить твою дизайн-систему і 1–3 рілси-референси, монтаж яких тобі подобається. Це один раз.
4. Далі Claude спитає текст хука, надішле сторінку перевірки, і ти затвердиш нарізку, графіку й субтитри. Потім напиши «збери чернетку», а після перегляду «фінал».

Готове відео лежить у папці **Фільми → Reels**.
